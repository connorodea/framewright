Craft AI videos from your terminal. Powered by Claude Code + HyperFrames.

$ npx framewright

Why framewright

01Skill-driven

Newly installed Claude Code skills become available with zero code changes. Trigger phrases like hyperframes, lottie, or gsap auto-load the right tools.

02Two modes

Interactive menu when you type fw. Headless subcommands when you script — same logic, no surprises.

03Hero one-liner

Capture a site and ship a video in a single command.

# turn any URL into a 30s promo
fw clone https://yoursite.com --out demo.mp4

Quick start

01 — Install

npx framewright or npm i -g framewright

02 — Clone a site

fw clone https://example.com

03 — Or script it

fw script "30s product tour"
